IHow GRPO Works

The model tries it 3 times independently:

Answer Correct? Reward
Rollout 1 a, b, c, d yes 1.0
Rollout 2 a, b, d, c no 0.0
Rollout 3 a, b, c, d yes 1.0

Average reward: (1.0 + 0.0 + 1.0) / 3 = 0.67. Now the advantage, how each rollout compares to the group mean:

Reward Advantage
Rollout 1 1.0 +0.33 better than average
Rollout 2 0.0 −0.67 worse than average
Rollout 3 1.0 +0.33 better than average

Why this matters for RL: the model can look at rollout 1 vs rollout 2 and ask "what did I do differently?" The positive advantage says "do more of this", negative says "do less of this." It learns from its own successes and failures on the same problem.

This is the core idea behind GRPO (Group Relative Policy Optimization). You don't need a separate reward model, you just compare the rollouts against each other within the group.

IIDr.GRPO

Dr.GRPO (Liu et al., 2025) makes two adjustments to standard GRPO. Both are about fairness: making sure no single group or response dominates the gradient just because of scale.

aGroup Std Normalization

GRPO advantage = reward − group_mean
DR.GRPO advantage = (reward − group_mean) / group_std

Groups with high reward variance produce larger advantages and dominate the gradient. Example, two groups, 4 rollouts each:

Group Rewards Mean Advantages
A [0, 0, 0, 1] 0.25 [-0.25, -0.25, -0.25, 0.75]
B [0.4, 0.5, 0.5, 0.6] 0.50 [-0.1, 0, 0, 0.1]

Group A's advantages are 7x larger. Without normalization, the model mostly learns from Group A (the easy question where one rollout got lucky) and ignores Group B (where it's actually making steady progress with nuanced signal). Dividing by std scales both groups to similar magnitude, every prompt contributes equally to learning.

Edge case: if all rollouts in a group score the same, std is 0. These groups get skipped (advantage = 0), which is correct, zero variance means no learning signal.

bResponse Length Normalization

Standard GRPO sums the loss over all tokens. Every token gets the same advantage, so longer responses have more impact on the gradient.

Tokens Reward Gradient weight
Rollout 1 400 0 400 tokens of negative signal
Rollout 2 50 1 50 tokens of positive signal
Rollout 3 200 0 200 tokens of negative signal

Without length normalization: 600 tokens of negative gradient vs 50 tokens of positive. The long wrong answer drowns out the short correct one. The model learns "don't be verbose" instead of "don't be wrong." With length normalization: each rollout's loss is divided by its token count, so each response contributes equally regardless of length.
